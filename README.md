# Análise de Dificuldades no Aprendizado de Inglês - TCC

Este repositório contém o código-fonte e os scripts de análise estatística desenvolvidos para o Trabalho de Conclusão de Curso (TCC).

##  Conteúdo do Repositório
* `respostas_formulario.csv`: Banco de dados anonimizado das respostas do formulário.
* `projeto_1_tcc.py` / `regressao_logistica.py`: Scripts de limpeza, Análise de Agrupamento (K-Means) e Regressão Logística.
* `/outputs`: Gráficos gerados (Curva ROC, Matriz de Confusão, Odds Ratios) e relatórios em formato CSV/TXT.

## Tecnologias Utilizadas
* Python 3
* Pandas & NumPy
* Scikit-Learn
* Matplotlib & Seaborn

## Como Executar
1. Clone o repositório: `(https://github.com/NadyeleSouza23/nadyele_tcc_usp_esalq_data_science.git)`
2. Instale as dependências: `pip install pandas numpy scikit-learn matplotlib seaborn scipy`
3. Execute o script principal: `python regressao_logistica.py`
